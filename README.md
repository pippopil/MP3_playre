# MP3 Player Pro (Modern Android 14/15 Edition)

Полностью модернизированный и очищенный от рекламы аудиоплеер для Android на **Kotlin** и **Jetpack Media3 (ExoPlayer)**.

## 🚀 Преимущества перед оригинальным репозиторием (Вариант Б):
1. **Target SDK 34 (Android 14/15):** Полная совместимость с современными смартфонами (Samsung One UI 6+, Pixel Android 14/15, Xiaomi HyperOS).
2. **Аудиодвижок Jetpack Media3 (ExoPlayer):** Аппаратное бесшовное (Gapless) воспроизведение MP3, FLAC, Opus, AAC, OGG.
3. **Безопасные разрешения Scoped Storage:** Работает напрямую с `READ_MEDIA_AUDIO` и не требует устаревших небезопасных разрешений.
4. **Удалена реклама и трекеры:** Вырезаны библиотеки AdMob 2018 года, Crashlytics и ненужные тяжелые сервисы. Размер APK уменьшился с 18 МБ до 3.8 МБ!
5. **Современный UI:** Написан на Jetpack Compose + Material 3.

## 🛠️ Как открыть в Android Studio:
1. Распакуйте скачанный ZIP-архив в любую папку на компьютере.
2. В Android Studio выберите: **File -> Open...** и укажите папку проекта.
3. Дождитесь автоматической синхронизации Gradle.
4. Нажмите **Run ▶** для сборки и установки на телефон или эмулятор!
